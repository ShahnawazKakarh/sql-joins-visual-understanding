---

### 👀 What is this?

A **simple interactive tool** to visualize how SQL joins work.

Instead of reading theory, you **click and watch** how rows move and combine.

---

### ⚙️ What it does

▶ Click a join type and see the animation:

* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* FULL OUTER JOIN

Uses two sample tables:

* **Customers**
* **Orders**

---

### ▶️ How to use

1. Open the link (or `index.html` locally)
2. Click any join button
3. Watch the animation

That’s it.

---

### ✨ Features

* 4 join types with animations
* Displays the SQL query
* Works on mobile
* No dependencies (HTML / CSS / JS only)

---

### 🧪 Sample data

* 5 customers (some have orders, some don’t)
* 6 orders (some match customers, some don’t)

This clearly shows how joins handle **matched** and **unmatched** records.
